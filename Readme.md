# Razorpay Clone

A Razorpay-inspired fintech landing page built with Tailwind CSS and Vite. This project focuses on recreating the premium SaaS-style UI of Razorpay with a modern, responsive design.

## Demo

Live preview can be opened locally via the Vite dev server after installation.

## Overview

This project is a front-end clone of Razorpay’s homepage, designed to practice responsive UI development, visual design, spacing, typography, and component structuring. The page includes a navigation bar, hero section, feature highlights, business-focused cards, trust branding, CTA sections, and a polished footer.

## Features

- Responsive landing page layout
- Razorpay-inspired color palette and branding
- Hero section with strong call-to-action styling
- Feature-rich fintech product section
- Clean SaaS-style card layouts
- Hover states and modern UI polish
- Tailwind-based utility-first styling

## Tech Stack

- HTML5

- JavaScript
- Tailwind CSS
- Vite
- PostCSS
- Autoprefixer

## Installation

1. Clone the repository
2. Install dependencies:

```bash
npm install
```

3. Start the dev server:

```bash
npm start
```

4. Open the local Vite URL in your browser.
